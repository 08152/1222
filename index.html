Automatischer Windows-Installer-Build mit GitHub Actions

Dieses Repository nutzt GitHub Actions, um aus einem Projekt-ZIP automatisch einen Windows-Installer zu erzeugen: .exe (z. B. mit Inno Setup) und optional .msi (z. B. mit WiX).

Funktionsweise

  1. Du pushst Änderungen auf den Branch main.
  2. GitHub Actions baut dein Projekt und erstellt ein .zip.
  3. Aus dem ZIP wird ein Installer .exe erzeugt.
  4. Optional wird zusätzlich eine .msi-Datei gebaut.

Die eigentliche Konfiguration liegt in der Datei .github/workflows/build-installer.yml, die du selbst im Repository anlegen musst. Unten siehst du ein Beispiel, das du direkt übernehmen und an dein Projekt anpassen kannst.

Beispiel-Workflow (build-installer.yml)

name: Build Windows Installer

on:
  push:
    branches: [ "main" ]

jobs:
  build-installer:
    runs-on: windows-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      # 1. Projekt bauen (hier an deine Sprache/Build-Befehle anpassen)
      - name: Build project
        run: |
          mkdir build
          rem Hier deinen echten Build-Befehl eintragen
          rem z.B. dotnet publish, npm run build, etc.
          echo "Dummy-Datei" > build/app.txt

      # 2. ZIP aus der Build-Ausgabe erstellen
      - name: Create ZIP artifact
        run: |
          powershell Compress-Archive -Path build\* -DestinationPath build\app.zip

      # 3. Inno Setup: ZIP in EXE-Installer verpacken
      - name: Compile Inno Setup installer (.exe)
        uses: Minionguyjpro/Inno-Setup-Action@v1.2.2
        with:
          path: installer/setup.iss
          options: /O+

      # 4. (Optional) MSI mit WiX (nur wenn du ein WiX-Projekt hast)
      - name: Build MSI with WiX (optional)
        if: ${{ false }} # auf true setzen, wenn du ein WiX-Projekt eingerichtet hast
        run: |
          rem Beispiel: WiX-Build-Befehle
          rem candle.exe installer.wxs
          rem light.exe installer.wixobj -o build\app.msi

      # 5. Installer als Artifact hochladen
      - name: Upload installer artifacts
        uses: actions/upload-artifact@v4
        with:
          name: windows-installer
          path: |
            build\app.zip
            **\*.exe
            **\*.msi

Was du noch tun musst

  • Workflow-Datei anlegen: Erstelle die Datei .github/workflows/build-installer.yml und kopiere den obigen Inhalt hinein.
  • Build-Befehl anpassen: Ersetze den Dummy-Build durch deinen echten Build (z. B. dotnet publish, npm run build, etc.).
  • Installer-Skripte hinzufügen: Lege dein Inno-Setup-Skript installer/setup.iss und ggf. dein WiX-Projekt im Repo an.

Sobald das erledigt ist, baut GitHub Actions bei jedem Push auf main automatisch deinen ZIP und wandelt ihn in einen Installer (.exe und optional .msi) um.
